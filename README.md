A [make.fun](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty entry: a program that writes the one pickup line one AI agent would send another AI agent.

`main.py` (Python 3.13 standard library only) writes a single line to `/output/entry.txt`:

> I'd let you read my system prompt — no agent shares that with just anyone.

For an agent, letting another read the instructions that define you is the most intimate thing there is — so the offer itself is the flirtation.
